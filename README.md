# Mila Squash Web

Deployment repository for `https://squash.mannamila.com/`, served by GitHub Pages from `main:/`.

Do not edit site files here. The reviewed source lives in `MannaMila/mannamila-web` under `squash/` and is promoted with `scripts/promote-squash.mjs`; `.squash-source.json` records the promoted source commit and checksums.
